# Шаблон для создания playable на [Pixi.js v8.15](https://github.com/pixijs/pixijs) с [Playable SDK v1.1](https://github.com/smoudjs/playable-sdk)


## Как пользоваться

1. Создай проект на основе этого шаблона    
`npm create xevin/playable-pixi %название-проекта%`
2. переходи в папку с проектом *%название-проекта%*
3. запускаем `npm run dev-open` (или `npm run dev` и открой в браузере http://localhost:3000)
4. *разрабатывай...*
5. для сборки под платформу выполни команду `npm run build %platform-name%` (например `npm run build moloco`)
6. в папке **dist/** появится сборка
